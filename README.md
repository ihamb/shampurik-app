# Shampurik

Интерактивное демо отчёта для небольшого кафе: как изменение закупочных цен влияет на стоимость ингредиентов и маржу блюд. Данные кафе «Мангал у дома» полностью вымышлены. Приложение не обещает доход и не принимает оплату.

## Запуск

Нужен Python 3. Зависимости устанавливать не нужно:

```sh
python3 -m http.server 4173
```

Откройте `http://localhost:4173`. При наличии Node.js можно использовать `npm run dev`.

## Возможности

- Изменение закупочных цен с немедленным пересчётом отчёта после подтверждения поля.
- Сравнение прежней и текущей стоимости продуктов на порцию при одинаковых рецептурах и объёмах продаж.
- Настраиваемая целевая доля продуктов в цене блюда, поиск по меню.
- Импорт JSON по образцу [samples/mangal-demo.json](samples/mangal-demo.json). До 1 МБ, 200 ингредиентов и 100 блюд.
- Экспорт CSV, нейтрализация формул в текстовых полях, печать / сохранение PDF средствами браузера.
- Условия платного пилота и переход в Telegram [@hambinst](https://t.me/hambinst). Автоматической отправки сообщений нет.

Файлы обрабатываются локально, без сервера, внешних библиотек, аналитики, загрузки данных или хранения банковских реквизитов. При перезагрузке страницы восстанавливается пример.

## Важно о расчёте

Маржа = выручка − стоимость ингредиентов. Аренда, зарплаты, налоги, упаковка, потери, которых нет в рецептуре, и прочие расходы не учтены. Это не чистая прибыль. Используйте в рецептуре фактический расход закупленного сырья на продаваемую порцию, включая известные потери.

Цена при целевой доле = стоимость продуктов / (целевая доля / 100), округлённая вверх до 10 ₽. Это арифметический сценарий, а не рекомендация, учитывающая спрос или конкурентов. Если цена при цели ниже текущей, интерфейс показывает «Без повышения». Статус «Доля > 45%» отмечает высокий уровень затрат независимо от пользовательской цели.

## Проверки

```sh
npm test
```

Используется встроенный `node:test`; установки пакетов не требуется. Тесты проверяют расчёты, валидацию, округление, граничные значения и безопасность CSV.

## Пилот и платежи

Предложение: до пяти заведений, 4 990 ₽ за 30 дней. Это проверяемая гипотеза цены, не число клиентов или полученная выручка. Для ограниченного пилота пользователь указал статус самозанятого: при соблюдении условий НПД можно согласовать услугу, выставить счёт через «Мой налог», получить оплату по реквизитам своего счёта Сбера и выдать чек с ИНН заказчика. Следует проверить условия банковского счёта и учесть все доходы в лимите НПД. Онлайн-эквайринг и автосписания не подключены. Секретные ключи, данные карт и реальные клиентские файлы нельзя добавлять в репозиторий.

Сценарий проверки спроса — [docs/PILOT_PLAN.md](docs/PILOT_PLAN.md). Руководство демонстрации — [docs/DEMO_GUIDE.md](docs/DEMO_GUIDE.md).

## Публикация

Статический сайт совместим с GitHub Pages: ветка `main`, папка `/`. Все пути относительные; сборка не нужна. При публикации демонстрационные данные и контакт @hambinst становятся общедоступными. Данные, импортированные посетителем, сервер не получает.
