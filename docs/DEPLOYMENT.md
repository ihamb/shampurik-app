# Размещение демо

Проверенная онлайн-версия: https://shampurik-menu-pilot-ihamb.sweetdegu10.chatgpt.site

Сайт создан и размещён через Sites. Аудитория — **только владелец**: по умолчанию новый Site приватный. Наличие URL не означает общий доступ для клиентов. Для внешних показов сейчас можно передавать PDF-отчёт; изменение аудитории — отдельное действие владельца.

Идентификатор Sites сохранён в `.openai/hosting.json`. Повторно создавать Site не нужно. Сайт был опубликован из изолированного каталога `/workspace/sites/shampurik-pilot`; секреты доступа не записывались в файлы или Git. Дальнейшие публикации должны использовать существующий Site и точный сохранённый исходный коммит.

`npm run build` собирает только статические `index.html`, `styles.css` и `src/` в игнорируемый каталог `dist/`. Приложению не нужны серверная база данных, ключи или платные API. В демо нет эквайринга, автоматической отправки заявок или платных клиентов.

## Альтернатива: GitHub Pages

Интеграция GitHub разрешила сохранить исходники, но отказала при включении Pages: HTTP 403 `Resource not accessible by integration`. Это ограничение прав интеграции, а не ошибка сайта.

Владелец репозитория может включить публичный сайт вручную: GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save. Репозиторий публичный, и в нём находятся только вымышленные данные, код, документы и предоставленный контакт @hambinst. Данные посетителей при импорте остаются в браузере.

- Браузерные проверки прошли: изменение цены, недопустимый ввод, сброс, целевая доля, поиск, импорт JSON, защита от HTML-инъекции, экспорт, диалог и Telegram-ссылка.
